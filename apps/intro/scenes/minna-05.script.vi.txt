## Mở bài
[1] みなさん、こんにちは。今日{きょう}は第{だい}5課{か}です。 // Chào các bạn. Hôm nay là bài 5.
[1] テーマは「どこへ、何{なに}で、だれと行{い}くか」です。 // Chủ đề: đi đâu, bằng gì, với ai.
## Từ vựng
[1] まず、言葉{ことば}を見{み}ましょう。 // Trước hết, cùng xem từ vựng.
[1] 行{い}きます、来{き}ます、帰{かえ}ります。 // Đi, đến, về.
[1] 「行{い}きます」は、ここからあそこへ行{い}くときに使{つか}います。 // "行きます" dùng khi đi từ đây đến chỗ kia.
[1] 「来{き}ます」は、あそこからここへ来{く}るときに使{つか}います。 // "来ます" dùng khi từ chỗ kia đến chỗ mình.
[1] 「帰{かえ}ります」は、自分{じぶん}の家{いえ}や国{くに}へ帰{かえ}るときに使{つか}います。 // "帰ります" dùng khi về nhà hay về nước mình.
## Ngữ pháp 1: へ
[1] では、一{ひと}つ目{め}の文法{ぶんぽう}です。 // Nào, ngữ pháp thứ nhất.
[1] 「へ」は矢印{やじるし}です。行{い}くところを見{み}せます。 // "へ" là mũi tên, chỉ nơi mình đi tới.
[1] 場所{ばしょ}のあとに「へ」、そして「行{い}きます」。 // Sau nơi chốn là "へ", rồi "ikimasu".
[1] 図書館{としょかん}へ行{い}きます。 // Tôi đi đến thư viện.
[1] 来週{らいしゅう}、大阪{おおさか}へ行{い}きます。 // Tuần sau tôi đi Osaka.
[1] 七時{しちじ}に家{いえ}へ帰{かえ}ります。 // Tôi về nhà lúc 7 giờ.
## Ngữ pháp 2: で
[1] 二{ふた}つ目{め}は「で」です。 // Thứ hai là "で".
[1] 「で」は乗{の}り物{もの}です。車{くるま}のようなものです。 // "で" là phương tiện, giống như chiếc xe.
[1] 電車{でんしゃ}で会社{かいしゃ}へ行{い}きます。 // Tôi đi làm bằng tàu điện.
[1] 自転車{じてんしゃ}で学校{がっこう}へ行{い}きます。 // Tôi đi học bằng xe đạp.
[1] 飛行機{ひこうき}で日本{にほん}へ来{き}ます。 // Tôi sẽ đến Nhật bằng máy bay.
[1] バスも、タクシーも、「で」です。 // Xe buýt hay taxi cũng đều dùng "で".
## Ngữ pháp 3: と
[1] 三{みっ}つ目{め}は「と」です。 // Thứ ba là "と".
[1] 「と」は、一緒{いっしょ}に行{い}く人{ひと}です。 // "と" là người đi cùng mình.
[1] 友達{ともだち}と映画館{えいがかん}へ行{い}きます。 // Tôi đi rạp phim với bạn.
[1] 家族{かぞく}と日本{にほん}へ来{き}ます。 // Tôi sẽ đến Nhật cùng gia đình.
[1] 先生{せんせい}と図書館{としょかん}へ行{い}きます。 // Tôi đi thư viện cùng thầy cô.
[1] 「と」の前{まえ}には、人{ひと}が入{はい}ります。 // Trước "と" là người.
